# Своё бистро — сайт с доставкой и бронью

Демо-концепт сайта для бистро с пекарней «Своё бистро» (Новоселье, бульвар Белых Ночей, 3).

Сайт: https://9554813-rgb.github.io/svoebistro/
Админ-панель: https://9554813-rgb.github.io/svoebistro/admin.html

## Что где лежит

| Файл / папка | Что это |
|---|---|
| `index.html` | Сам сайт: меню по группам, корзина, оформление заказа, бронь стола. Фото вшиты в файл. |
| `admin.html` | Админ-панель: заказы и брони, статусы, автообновление, звук на новые. |
| `privacy.html` | Политика обработки персональных данных (**шаблон**, проверить у юриста). |
| `soglasie.html` | Согласие на обработку персональных данных (**шаблон**, проверить у юриста). |
| `server/Code.gs` | Сервер заказов для Google Apps Script. **Работает не здесь**: его вставляют в Google Таблицу. |
| `source/` | Исходники, из которых собраны страницы (Python), и тестовый стенд сервера. |

## Как работают заказы

```
Сайт → сервер (Google Apps Script) → Google Таблица (листы «Заказы» и «Брони»)
                                   ↘ Telegram: уведомление персоналу (без телефона и адреса)
Админ-панель ← читает таблицу и меняет статусы
```

Сервер сам пересчитывает цены по своему прайсу, присваивает номера (№ 1001…, Б-101…)
и проверяет минимальную сумму доставки.

## Подключение (10–15 минут)

1. Telegram: **@BotFather** → `/newbot` → скопировать токен. Написать боту любое сообщение.
2. Новая Google Таблица → **Расширения → Apps Script** → вставить код из `server/Code.gs` → сохранить.
3. ⚙ **Настройки проекта → Свойства скрипта**: `TG_TOKEN` (токен), `ADMIN_KEY` (длинный пароль для админки).
4. Выполнить функцию `setup` → разрешить доступ. Затем `findChatId` → добавить свойство `TG_CHAT_ID`. Проверить: `testTelegram`.
5. **Начать развёртывание → Веб-приложение**: «Выполнять от имени — я», «Доступ — все». Скопировать ссылку `…/exec`.
6. В `index.html` в самом начале: `window.API_URL = ''` → вставить ссылку между кавычками.
7. Открыть `admin.html` → ввести ссылку и `ADMIN_KEY`.

Необязательные свойства скрипта: `ADMIN_URL` (кнопка «Открыть админ-панель» в Telegram),
`NOTIFY_STATUS = yes` (сообщать в Telegram о смене статуса),
`TG_FULL = yes` (присылать в Telegram имя, телефон и адрес — решение за юристом, см. ниже).

> После правки кода скрипта: **Развёртывание → Управление → ✎ → Новая версия**, иначе изменения не применятся.

## Перед настоящим запуском

- Заполнить в `privacy.html` и `soglasie.html` поля в квадратных скобках (ОГРН, адрес, e-mail, сроки, CRM) и убрать плашку «Черновик».
- Заполнить сведения о продавце: `source/common.py` → `CFG['seller']` (ИНН взят из карточки на Яндекс Картах — сверить).
- Персональные данные граждан РФ при сборе должны записываться в базы на территории РФ (152-ФЗ, ст. 18, ч. 5).
  Google Таблица — зарубежный сервис: для показа и теста, но для работы лучше российская CRM.
- Проверить документы у юриста. Подать уведомление об обработке ПДн в Роскомнадзор (ст. 22 152-ФЗ), если ещё не подано.

## Как пересобрать сайт из исходников

Нужен Python 3 и архив фото `svoe-bistro-photos.zip` (путь задан в `source/common.py`):

```
cd source
python3 designs.py   # собирает варианты дизайна в out/ (8-flavoria-polnostyu.html → index.html)
python3 legal.py     # privacy.html и soglasie.html
```

Тест сервера без Google и Telegram: `node test/mock-server.js <папка с сайтом> 8765`.
