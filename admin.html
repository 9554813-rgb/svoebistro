Админ-панель заказов и броней

Как подключить (10–15 минут)
  1. Бот. В Telegram откройте @BotFather → /newbot → придумайте имя. Скопируйте токен.
  2. Чат. Напишите своему боту любое сообщение. Для общего чата персонала — создайте группу и добавьте туда бота.
  3. Таблица. Создайте новую Google Таблицу → Расширения → Apps Script. Удалите всё в редакторе и вставьте код из файла Code.gs. Сохраните.
  4. Свойства. Слева ⚙ Настройки проекта → Свойства скрипта: добавьте TG_TOKEN (токен) и ADMIN_KEY (придумайте длинный пароль).
  5. Первый запуск. Вверху выберите функцию setup → Выполнить → разрешите доступ. Появятся листы «Заказы» и «Брони».
  6. id чата. Выполните функцию findChatId — в журнале появится id. Добавьте свойство TG_CHAT_ID с этим числом. Выполните testTelegram — придёт сообщение.
  7. Публикация. Начать развёртывание → Новое развёртывание → Веб-приложение: «Выполнять от имени — я», «Доступ — все». Скопируйте ссылку …/exec.
  8. Сайт. Откройте файл сайта в Блокноте, в самом начале найдите window.API_URL = '' и вставьте ссылку между кавычками.
  9. Админка. Вставьте ту же ссылку и ключ на этом экране. Готово!

После правки кода скрипта нужно «Развёртывание → Управление → ✎ → Новая версия», иначе изменения не применятся.
